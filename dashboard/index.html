Pacujá CE — Painel de desempenho

Como ler este painel
  • Unidade: número de equipes. Pacujá tem poucas equipes (por exemplo, 3 eSF): cada equipe pesa muito, e “1 de 3” é 33%.
  • Conceito (Ótimo, Bom, Suficiente, Regular) é a classificação oficial do Ministério. Não é percentual de execução das práticas — os percentuais mensais não são públicos.
  • Resultado do quadrimestre = média dos meses monitorados. A janela de monitoramento (30 dias a 60 meses, conforme o indicador) é o período observado em cada mês, não o período da média.
  • Componentes II e III avaliam as mesmas equipes de Saúde da Família por critérios diferentes. Os grupos se sobrepõem: não os some.
  • Nota média estimada é uma média municipal calculada a partir das contagens públicas. Não é a nota de nenhuma equipe nem define o valor do incentivo.
